# Algorithm32 Production References

This folder owns curated source references for production Algorithm32 tests,
fixtures, and implementation.

Production physics and algorithm citations now live in
`../references.md` as AMA-style numbered references. Code comments should cite
that list with bracketed reference numbers after a short description of the
data, formula, algorithm decision, or algorithm variation being cited. Use
ASCII tokens such as `[1]`, `[2]`, and `[1][2]`, not Unicode superscripts,
Markdown footnotes, or HTML citation markup.

The older `source-registry.json` file is retained as scaffold history until the
reference scaffolding is fully retired or migrated.
