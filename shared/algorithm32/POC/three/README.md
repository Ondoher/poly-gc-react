# Three Shader POC

Pure importable Three-native atmosphere pass extracted from the accepted
shader-lab page.

`shader-lab-page.js` now contains only the `Algorithm32AtmospherePass` class,
its render-target helper, pass/config helpers, and the accepted first-order
distant/local shader body. The browser page harness, scenario controls,
artifact generation, and validation-gallery code were removed from this POC
copy.

This is still POC source, not yet the production Three module.
