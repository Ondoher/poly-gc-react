# Bootstrap

Load these documents at the start of a session:

1. [Active Topic](../active-topic.md)
2. [Agent Topics](../README.md)
3. [Routing](routing.md)
4. [Architecture Overview](../standards/architecture/overview.md)

If the active topic names a product, app, standard, or restructure topic, load
that topic's README next. Then load only the focused reload sources named by
the active topic.

If the active topic says a task is clean-room, source-restricted, or
routing-only, keep bootstrap to that boundary. Do not load adjacent history,
archives, old local implementation docs, or extra topic links simply because
they are nearby.

Do not load migrated historical docs from `agents/topics.bak` unless the active
task needs them.

Agent-facing docs should be current-state docs by default. Historical material
belongs only in experiment evidence, intentional status/task trackers, or
clearly marked archives.
