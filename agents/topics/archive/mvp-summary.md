# MVP Summary

The MVP topic is historical. It tracked the first meaningful GC/Mahjongg
release and no longer owns active product scope.

## Delivered

- Friends-and-family Mahjongg Solitaire release scope.
- Feedback dialog and `/gc/api/feedback` backend storage.
- Gameplay telemetry submission to `/gc/api/telemetry`.
- Startup consent and cookie-backed preferences.
- Telemetry consent behavior that affects the active game immediately.
- Installable-first PWA configuration for GC/Mahjongg, including manifest,
  icons, theme color, copied build resources, and linked template metadata.
- Portrait fallback behavior for the first release.
- Local/server validation for feedback, telemetry, consent persistence,
  installability, and clean redeploy/update flow.
