# Flat Plans

Future Flat app implementation plans live here.

- [POC Phase 1 Plan](poc-phase-1-plan.md)
- [Algorithm32 Production Documentation](../algorithm32/README.md) -
  production documentation home for the official Algorithm32 module. The
  implementation lives in `shared/algorithm32/`.
- [Atmosphere Cleanroom Design](atmosphere-cleanroom-design/README.md) - new
  reset documentation home for incorporating the closed cleanroom evidence
  lane and replacing the rejected reference pipeline.
- [Experiment 032 Algorithm](atmosphere-cleanroom-design/experiment-032-algorithm.md) -
  source-backed algorithm, constants, equations, and algorithmic choices for
  the current Figure 1 handoff candidate.
- [Object Color Transport](atmosphere-cleanroom-design/object-color-transport.md) -
  finite-segment atmospheric transfer contract for objects and ground surfaces.
- [Reference To Shader Goal](atmosphere-cleanroom-design/reference-to-shader-goal.md) -
  end-state goal for using the cleanroom reference to build the production
  atmosphere shader, including cache-builder and parity expectations.
- [Algorithm32 Module Design](atmosphere-cleanroom-design/algorithm32-module-design.md) -
  working interface design for packaging Algorithm32 as reusable direct-trace,
  cache-builder, preset, and shader-validation code.
- [Algorithm32 Shader Iteration Plan](atmosphere-cleanroom-design/algorithm32-shader-iteration-plan.md) -
  immediate resumable iteration ladder for building the browser shader path
  against the CPU Algorithm32 reference.
- [Algorithm32 Shader Lab Plan](atmosphere-cleanroom-design/algorithm32-shader-lab-plan.md) -
  experimental harness plan for validating browser reload control, Node/Three
  CPU reference rendering, and shader parity against Algorithm32.
- [Local Sun Second-Order POC](atmosphere-cleanroom-design/local-sun-second-order/README.md) -
  cleanroom POC planning tracker for local Sun second-order scattering parity,
  objective scene measurements, CPU soft-shader proof, and integrated GPU
  proof.
- [Object Transport Experiment Plan](atmosphere-cleanroom-design/object-transport-experiment-plan.md) -
  closed cleanroom experimental lane that proved object color transfer before
  the production pipeline.
- [Environment Object Color Prompt](atmosphere-cleanroom-design/environment-object-color-prompt.md) -
  closed prompt for the environment-object color experiment under
  `scripts/flat/atmosphere-environment/`, with numbered outputs under
  `tmp/atmosphere/cleanroom_environment/`.
- [Objective Success Criteria](atmosphere-cleanroom-design/objective-success-criteria.md) -
  reference-backed pass/fail criteria for the environment-object transfer
  proof, including transport identities, convergence-backed thresholds, and
  display-only checks.
- [Environment Experiment Run Shape](atmosphere-cleanroom-design/environment-experiment-run-shape.md) -
  proposed execution sequence, input packets, output artifacts, and minimal 3D
  ray-test scene model for the cleanroom environment-object experiments.
- [Environment Experiment Preflight Spec](atmosphere-cleanroom-design/environment-experiment-preflight-spec.md) -
  first-run decisions for experiment 032 constants, Bruneton sunrise/highest
  Sun cases, stress spectra/distances, audit-trail input/output shape, and the
  required running log.
- [Retired Atmosphere Material](retired/README.md) - historical atmosphere
  reset, Bruneton/skydome, spherical-sun, reality-aligned, and visual baseline
  material superseded by the cleanroom/Algorithm32 canon.
