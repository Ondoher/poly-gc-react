# Retired Flat Atmosphere Material

This folder contains Flat atmosphere-centered documents and visual baselines
that are no longer current Algorithm32 authority. "Retired" here means they
are not the active design home; it does not mean the documents are stale or
useless as source/provenance material.

Moved here on 2026-06-25 during the cleanroom/Algorithm32 documentation reorg.
Use
`../atmosphere-cleanroom-design/algorithm32-canonical-reference.md`
as the current source of truth for Algorithm32 status, abstractions, accepted
end states, open issues, and production followups.

## Use Policy

- Do not use these docs as active design authority.
- Mine them when the user asks for predecessor context, source/reference
  provenance, or doc reorg evidence.
- Promote useful facts into the cleanroom canon instead of adding new active
  dependencies on retired docs.
