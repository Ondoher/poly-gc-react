## Current Shape

Flat is a Polylith REMVC app with an active false-simulation feature. The first
POC focuses on the counterfactual sky model; the standard sky viewer remains
future scope.

The old mixed README content is preserved in [Status](status.md). A later
content pass can rebalance that file into smaller status, decision, data-source,
and rendering docs.
