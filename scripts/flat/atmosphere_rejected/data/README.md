# Atmosphere Data

Shared source artifacts and scenario inputs for the atmosphere script packages.

- `color/`: CIE color matching data and ASTM G-173 solar spectrum artifacts.
- `composition/`: physical atmosphere composition source artifacts, currently
  Bucholtz 1995 Rayleigh data, Brion 1998/MPI-Mainz ozone cross sections,
  first aerosol presets, and U.S. Standard Atmosphere 1976 density checkpoints.
- `reference/`: reference-run scenario/config data, currently flat
  light-extent scenario sets.
