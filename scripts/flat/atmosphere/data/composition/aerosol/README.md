# Aerosol Composition Data

`aerosol-presets.json` stores the first named aerosol/Mie policy inputs for
the atmosphere reference runner. The values are compact clear-sky comparison
presets: aerosol optical depth at `550 nm`, Angstrom exponent,
single-scattering albedo, exponential scale height, and Henyey-Greenstein
asymmetry parameter.

The source artifact records the measurement/model families used to choose the
parameters. These presets are scenario handles for visual comparison, not a
global climatology or a replacement for future AERONET/libRadtran validation.
